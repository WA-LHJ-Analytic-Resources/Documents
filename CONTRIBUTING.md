# Contributing to WA LHJ Analytic Resources

**Thank you for your interest in contributing!**  
This organization is a shared space for Epidemiologists across local public health departments in Washington to share code, tools, and best practices for epidemiologic analysis and reporting.

## How to Contribute

- Fork the repository you want to contribute to.
- Create a branch for your feature or fix.
- Make your changes with clear, well-documented code.
- Submit a pull request with a description of your changes and why they are useful.
- Participate in review by responding to feedback and making necessary updates.

## Code of Conduct

We aim to foster a welcoming and respectful environment. All contributors must adhere to our Code of Conduct. Please read it before participating.

## Types of Contributions

We welcome a variety of contributions, including:

- 📦 Reusable R functions or R packages  
- 📊 Visualization templates (e.g., ggplot2, plotly, leaflet)  
- 📄 Report templates (e.g., RMarkdown, Quarto)  
- 🧪 Unit tests and validation scripts  
- 📚 Documentation and tutorials  
- 🧭 Workflow automation (e.g., GitHub Actions, R Markdown pipelines)  

## Development Guidelines

- Use clear, descriptive commit messages.  
- Follow consistent naming conventions and tidyverse code style.  
  - [Best Practices (Short)](https://r4ds.hadley.nz/workflow-style.html)  
  - [Best Practices (All)](https://style.tidyverse.org/syntax.html)  
- Include docstrings or comments for all functions.  
- Add example data or simulated datasets when demonstrating code.  
- Write unit tests where applicable.
- If pre-existing R code is utilized, incorporated, forked, or adapted, ensure that the **original authors are credited** clearly in documentation or comments.  

## Data Privacy

Do not upload any real or identifiable health data.  
All shared code must use:

- Simulated data  
- Publicly available datasets  
- De-identified examples
